Input: string s=abccbad
Goal: find the length of the longest substring without repeating chars.

note: 

visualisation of how it works:

input. 
    (abccbad)

0. 
    []abccbad
    L
    R
    set()
    max: 0
    
    * initialize 
    * keep track of the chars we have in the wwindoww we will use an 'HASH SET' -> aka 'set()'.
    * we'll keep track of the max substring length in 'max'
    * '[]' this is the window that were going to slide. note: this is only visual, and 'R' & 'L' is what we will actually use.
    * 'L' and 'R' represents the "[]-handles"
1. 
    [a]bccbad
     L
     R
    set(a,)
    counter: 0+=1 => 1
    max: counter>max: max=counter => 1
    
    * 'a' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'a' (window right handle)
    * increment counter += 1.
    * counter > max -> max=counter. 

    [ab]ccbad
     L
      R
    set(a,b)
    counter: 1+=1 => 2
    max: counter>max: max=counter => 2

    * 'b' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'b' (window right handle)
    * increment counter += 1.
    * counter > max -> max=counter. 
3. 
    [abc]cbad
     L
       R
    set(a,b,c)
    counter: 2+=1 => 3
    max: counter>max: max=counter => 3

    * 'c' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'c' (window right handle)
    * increment counter += 1.
    * counter > max -> max=counter. 

4. 
    abc[c]bad
        L
        R
    set(c,)
    counter: 0+=1 => 1
    max: counter!>max: max!=counter => 3

    > HERE is where it gets interesting;
    > 'c' is already in our set, so we cannot add it.
    > therefore we have to:
    * 'R' slides to index of 'c' (window right handle)
    * 'L' slides to index of 'c' (or to position of 'R') (window left handle)
    * 'c' EXIST in our set so we cannot add it to the current set, and we have to make a new one.
    * set gets reset to empty
    * 'c' DONT_EXIST in our "reset" set so we can add it.
    * counter resets to 0
    * increment counter += 1
    * counter !> max, so max remains (max=3).


5. 
    abc[cb]ad
        L
         R
    set(c,b)
    counter: 1+=1 => 2
    max: counter!>max: max!=counter => 3

    * 'b' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'b' (window right handle)
    * increment counter += 1.
    * counter !> max, so max remains (max=3).

6. 
    abc[cba]d
        L
          R
    set(c,b,a)
    counter: 3+=1 => 3
    max: counter!>max: max!=counter => 3

    * 'a' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'a' (window right handle)
    * increment counter += 1.
    * counter !> max, so max remains (max=3).


7. 
    abc[cbad]
        L
           R
    set(c,b,a,d)
    counter: 3+=1 => 4
    max: counter>max: max=counter => 4

    * 'd' DONT_EXIST in our set so we can add it.
    * 'R' slides to index of 'd' (window right handle)
    * increment counter += 1.
    > NOW counter IS bigger than max and we need to update max
    * counter > max -> max=counter. 


output.
    => return max = 4
